# Progress

Waypoint automatically calculates and updates a `progress` value (0–100) for each journey.

## Calculation

Progress is calculated by `calculateStepProgress` from `@waypoint/core`:

```ts
progress = ((stepIndex + 1) / (totalSteps + 1)) * 100
```

The `+1` in the denominator ensures the last step never reaches 100%, leaving room to indicate "completion" only when all steps are done.

## Automatic updates

Progress is updated automatically whenever `currentStep` changes — you don't need to manage it manually.

## Reading progress

```tsx
import { useWaypointStore } from "@waypoint/core";

function ProgressBar() {
  const progress = useWaypointStore(
    (s) => s.getJourney("myJourney")?.progress ?? 0
  );
  return <progress value={progress} max={100} />;
}
```

## Manual override

You can manually set progress if needed:

```ts
useWaypointStore.getState().setProgress("myJourney", 75);
```
