# @waypointjs/next

Next.js App Router integration. Provides `WaypointRunner` (context provider) and `useWaypointStep` (per-page hook with react-hook-form + Zod).

```bash
pnpm add @waypointjs/next @waypointjs/core
```

---

## \<WaypointRunner\>

A React provider that initialises an isolated Zustand store, handles persistence, deep-link resume and exposes callbacks for data lifecycle events.

```tsx
import { WaypointRunner } from "@waypointjs/next";

<WaypointRunner
  schema={schema}
  externalVars={{ userId: "42" }}
  onComplete={async (data) => { /* save data, redirect */ }}
  onStepComplete={async (stepId, stepData) => { /* per-step save */ }}
  onDataChange={(data) => { /* any field changed */ }}
>
  {children}
</WaypointRunner>
```

### Props

| Prop | Type | Required | Description |
|---|---|---|---|
| `schema` | `WaypointSchema` | ✓ | The journey definition |
| `externalVars` | `Record<string, unknown>` | | External variable values referenced by conditions |
| `defaultValues` | `Record<string, Record<string, unknown>>` | | Pre-populated form data |
| `fetchData` | `() => Promise<Record<string, Record<string, unknown>>>` | | Async loader for saved data — called once on mount |
| `onComplete` | `(data) => void \| Promise<void>` | | Called when the last step is submitted |
| `onStepComplete` | `(stepId, stepData) => void \| Promise<void>` | | Called after each step is validated and submitted |
| `onDataChange` | `(data) => void` | | Called on every field value change |
| `children` | `React.ReactNode` | ✓ | Step pages |

### Init / Resume logic

On mount, `WaypointRunner`:

1. Creates a store via `createRuntimeStore({ persistenceMode, schemaId })`
2. If `persistenceMode === "zustand"` and `hasPersistedState(store, schemaId)` → calls `resume(schema, externalVars)`
3. Otherwise → calls `init(schema, { data: defaultValues || fetchData() })`
4. After init, if data is present → navigates to `findLastValidStep()` (deep-link resume)

When `externalVars` prop changes after mount, the runner calls `store.setExternalVar()` for each changed key — the tree re-resolves automatically.

<Callout type="warning">
  `WaypointRunner` must be a **Client Component** (`"use client"`). Place it in a layout file, not a page.
</Callout>

## useWaypointStep()

Per-page hook that auto-detects the current step from the URL, provides a react-hook-form instance pre-configured with the step's Zod schema, and handles validation + navigation on submit.

```tsx
import { useWaypointStep } from "@waypointjs/next";

const {
  currentStep,
  fields,
  form,
  handleSubmit,
  goBack,
  progress,
  isFirstStep,
  isLastStep,
  isSubmitting,
  errors,
} = useWaypointStep();
```

<Callout>
  Must be called inside a component that is a descendant of `<WaypointRunner>`.
</Callout>

### Return value

| Property | Type | Description |
|---|---|---|
| `currentStep` | `ResolvedStep \| undefined` | The step matched to the current URL |
| `fields` | `ResolvedField[]` | Visible fields for this step |
| `form` | `UseFormReturn` | react-hook-form instance — pre-wired to Zod schema |
| `handleSubmit` | `() => Promise<void>` | Validate → persist → navigate |
| `goBack` | `() => void` | Navigate to previous step |
| `progress` | `number` | 0–100 based on position in visible tree |
| `isFirstStep` | `boolean` | No previous step in resolved tree |
| `isLastStep` | `boolean` | No next step in resolved tree |
| `isSubmitting` | `boolean` | True while handleSubmit is running |
| `errors` | `FieldErrors` | react-hook-form validation errors |

### handleSubmit flow

1. Validate form via react-hook-form + Zod (built from `buildZodSchema(fields)`)
2. Persist step data into the store: `store.setStepData(stepId, values)`
3. Re-resolve tree with new data
4. If visible step IDs changed → `truncateHistoryAt(stepId)` (prevents stale forward history)
5. Call `onDataChange` callback
6. Call `onStepComplete` callback (awaited)
7. If more steps → navigate to `next.definition.url` via `router.push()`
8. If last step → call `onComplete(allData)`

### Example — full step page

```tsx
// app/onboarding/personal/page.tsx
"use client";

import { useWaypointStep } from "@waypointjs/next";

export default function PersonalPage() {
  const { fields, form, handleSubmit, goBack, progress, isFirstStep, isLastStep } =
    useWaypointStep();

  return (
    <div className="max-w-md mx-auto py-12">
      {/* Progress */}
      <div className="h-1 bg-gray-200 rounded mb-8">
        <div className="h-full bg-blue-500 rounded" style={{ width: `${progress}%` }} />
      </div>

      <form onSubmit={form.handleSubmit(handleSubmit)} className="flex flex-col gap-4">
        {fields.map((field) => (
          <div key={field.definition.id}>
            <label className="block text-sm font-medium mb-1">
              {field.definition.label}
            </label>
            <input
              type={field.definition.type}
              className="w-full border rounded px-3 py-2"
              placeholder={field.definition.placeholder}
              {...form.register(field.definition.id)}
            />
            {form.formState.errors[field.definition.id] && (
              <p className="text-red-500 text-xs mt-1">
                {String(form.formState.errors[field.definition.id]?.message)}
              </p>
            )}
          </div>
        ))}

        <div className="flex gap-3 mt-4">
          {!isFirstStep && (
            <button type="button" onClick={goBack} className="px-4 py-2 border rounded">
              ← Back
            </button>
          )}
          <button type="submit" className="px-6 py-2 bg-blue-600 text-white rounded">
            {isLastStep ? "Finish ✓" : "Continue →"}
          </button>
        </div>
      </form>
    </div>
  );
}
```

## useWaypointRuntimeContext()

Access the raw `WaypointRunner` context from any descendant component.

```ts
import { useWaypointRuntimeContext } from "@waypointjs/next";

const { schema, store, onComplete, onStepComplete, onDataChange } =
  useWaypointRuntimeContext();
```

Returns `WaypointRuntimeContextValue`:

```ts
interface WaypointRuntimeContextValue {
  schema: WaypointSchema;
  store: StoreApi<WaypointRuntimeStore>;
  onComplete?: (data: Record<string, Record<string, unknown>>) => void | Promise<void>;
  onStepComplete?: (stepId: string, data: Record<string, unknown>) => void | Promise<void>;
  onDataChange?: (data: Record<string, Record<string, unknown>>) => void;
}
```

Useful when you need direct store access alongside `useWaypoint()` from `@waypointjs/react`.
