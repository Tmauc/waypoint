# @waypointjs/core

Framework-agnostic engine. Zero React dependency. All other packages build on top of this one.

```bash
pnpm add @waypointjs/core
```

---

## createRuntimeStore()

Creates an isolated Zustand vanilla store for a single journey.

```ts
import { createRuntimeStore } from "@waypointjs/core";

const store = createRuntimeStore();
// or with localStorage persistence:
const store = createRuntimeStore({ persistenceMode: "zustand", schemaId: "onboarding" });
```

### Options

| Prop | Type | Description |
|---|---|---|
| `persistenceMode` | `string` | `"zustand"` activates localStorage persist middleware |
| `schemaId` | `string` | Used as part of the localStorage key: `waypoint-runtime-{schemaId}` |

### Store state

```ts
interface WaypointRuntimeState {
  schema: WaypointSchema | null;
  data: Record<string, Record<string, unknown>>; // { stepId: { fieldId: value } }
  externalVars: Record<string, unknown>;
  currentStepId: string | null;
  history: string[];      // step IDs visited in order
  isSubmitting: boolean;
  completed: boolean;
}
```

### Store actions

| Action | Signature | Description |
|---|---|---|
| `init` | `(schema, options?) => void` | Fresh start — resets all navigation state |
| `resume` | `(schema, externalVars?) => void` | Update schema/vars, keep data and navigation |
| `setFieldValue` | `(stepId, fieldId, value) => void` | Set a single field |
| `setStepData` | `(stepId, data) => void` | Replace all data for a step |
| `setExternalVar` | `(varId, value) => void` | Set an external variable |
| `setCurrentStep` | `(stepId) => void` | Navigate to a step |
| `truncateHistoryAt` | `(stepId) => void` | Remove all history after stepId |
| `reset` | `() => void` | Clear all state |

## resolveTree()

Pure function — evaluates all conditions and returns the visible tree.

```ts
import { resolveTree } from "@waypointjs/core";

const tree = resolveTree(schema, data, externalVars);
// { steps: ResolvedStep[], hiddenSteps: ResolvedStep[], missingExternalVars: string[] }
```

See [Tree Resolution](/concepts/history) for full documentation.

## Navigation helpers

```ts
import { getNextStep, getPreviousStep, calculateProgress, findLastValidStep } from "@waypointjs/core";

getNextStep(steps, currentStepId)      // ResolvedStep | undefined
getPreviousStep(steps, currentStepId)  // ResolvedStep | undefined
calculateProgress(steps, currentStepId) // number (0–100)
findLastValidStep(steps, data, externalVars) // ResolvedStep | undefined
```

## buildZodSchema()

Generates a Zod validation schema from an array of resolved fields.

```ts
import { buildZodSchema } from "@waypointjs/core";

const zodSchema = buildZodSchema(fields); // z.ZodObject
const result = zodSchema.safeParse(formValues);
```

Supported validation rules: `required`, `min`, `max`, `minLength`, `maxLength`, `email`, `url`, `regex`, `custom`.

```ts
// Register a custom validator before using it
import { registerCustomValidator } from "@waypointjs/core";

registerCustomValidator("strongPassword", (value) => {
  return typeof value === "string" && value.length >= 8 && /\d/.test(value);
});
```

## Condition functions

```ts
import { evaluateConditionGroup, isVisible, resolveFieldValue } from "@waypointjs/core";

// Evaluate a ConditionGroup
evaluateConditionGroup(group, data, externalVars) // boolean

// Shorthand — undefined returns true
isVisible(group, data, externalVars)              // boolean

// Resolve a dot-path to its value
resolveFieldValue("stepId.fieldId", data, externalVars) // unknown
```

## validateSchema()

```ts
import { validateSchema, assertSchema } from "@waypointjs/core";

const result = validateSchema(parsed);
// { valid: boolean, errors?: string[] }

assertSchema(parsed); // throws if invalid
```

## Computed state helpers

These are thin wrappers around `resolveTree()` that read directly from a store state object:

```ts
import {
  getResolvedTree,
  getCurrentStep,
  getNextStepFromState,
  getPreviousStepFromState,
  calculateProgressFromState,
  getMissingBlockingVars,
} from "@waypointjs/core";

const state = store.getState();
getResolvedTree(state)             // ResolvedTree
getCurrentStep(state)              // ResolvedStep | undefined
getNextStepFromState(state)        // ResolvedStep | undefined
getPreviousStepFromState(state)    // ResolvedStep | undefined
calculateProgressFromState(state)  // number (0–100)
getMissingBlockingVars(state)      // string[]
```

## hasPersistedState()

```ts
import { hasPersistedState } from "@waypointjs/core";

// Returns true if localStorage has valid state for this schema
hasPersistedState(store, schemaId) // boolean
```

Used internally by `WaypointRunner` to decide whether to call `resume()` or `init()`.
