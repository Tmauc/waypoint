# Waypoint

**Schema-driven multi-step journey framework for React & Next.js**

Waypoint turns complex multi-step flows (onboarding, checkout, wizards) into a portable JSON schema you can build visually, validate strictly, and render anywhere.

## How it works

1. **Define a schema** — steps, fields, validation rules, and visibility conditions in a single `WaypointSchema` JSON object
2. **Render with WaypointRunner** — the provider initialises a Zustand store, handles persistence and deep-link resume
3. **Use hooks in each step** — `useWaypointStep()` gives you a react-hook-form instance pre-wired to the step's Zod schema

The schema is self-contained. Export it, commit it, pass it as a prop — Waypoint is stateless until you mount a runner.

## Packages

| Package | Description |
|---|---|
| `@waypointjs/core` | Schema types · condition engine · tree resolver · Zustand runtime store · Zod generator |
| `@waypointjs/react` | Headless hooks (`useWaypoint`, `useWaypointStep`) — router-agnostic |
| `@waypointjs/next` | Next.js App Router integration (`WaypointRunner`, `useWaypointStep` with RHF + Zod) |
| `@waypointjs/builder` | Embeddable no-code UI for building and testing schemas |

## Quick install

```bash
# Next.js App Router
pnpm add @waypointjs/next @waypointjs/core

# Plain React (any router)
pnpm add @waypointjs/react @waypointjs/core
```

## Minimal example

```tsx
// 1. Define a schema (or generate one with <WaypointBuilder>)
const schema: WaypointSchema = {
  version: "1",
  id: "onboarding",
  name: "User Onboarding",
  steps: [
    {
      id: "personal",
      title: "Personal info",
      url: "/onboarding/personal",
      fields: [
        { id: "name",  type: "text",  label: "Full name",  validation: [{ type: "required", message: "Required" }] },
        { id: "email", type: "email", label: "Email address", validation: [{ type: "required", message: "Required" }, { type: "email", message: "Invalid email" }] },
      ],
    },
    {
      id: "confirm",
      title: "Confirm",
      url: "/onboarding/confirm",
      fields: [],
    },
  ],
};

// 2. Wrap your pages with WaypointRunner
// app/onboarding/layout.tsx
export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <WaypointRunner schema={schema} onComplete={(data) => console.log(data)}>
      {children}
    </WaypointRunner>
  );
}

// 3. In each step page
// app/onboarding/personal/page.tsx
export default function PersonalPage() {
  const { fields, form, handleSubmit, progress, isFirstStep } = useWaypointStep();
  return (
    <form onSubmit={handleSubmit}>
      <progress value={progress} max={100} />
      {fields.map((f) => (
        <input key={f.definition.id} {...form.register(f.definition.id)} />
      ))}
      <button type="submit">Continue →</button>
    </form>
  );
}
```
