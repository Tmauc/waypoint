# Waypoint

**Multi-step journey navigation for React & Next.js**

Waypoint is a framework-agnostic library that handles the complexity of multi-step, multi-journey navigation:

- **Step tree** — declarative navigation structure with URL templating
- **History management** — automatic back/forward with `purge-future` semantics
- **Progress tracking** — built-in progress calculation per journey
- **Resume support** — deep-link to the last visited step
- **Parallel journeys** — isolated state for multiple concurrent flows

## Packages

| Package | Description |
|---|---|
| `@waypoint/core` | Zustand store + types + URL engine (0 React dependency) |
| `@waypoint/react` | React hooks (`useWaypoint`, `useWaypointInitializer`, `useStepWaypoint`) |
| `@waypoint/next` | Next.js App Router drop-in (auto-injects `useRouter`) |

## Quick install

```bash
# Next.js project
pnpm add @waypoint/next @waypoint/core zustand
```

```bash
# React project (any router)
pnpm add @waypoint/react @waypoint/core zustand
```

## Quick example

```tsx
// 1. Define your journey tree
const MY_TREE = [
  {
    category: "personal",
    steps: [
      { step: "name",    url: "/onboarding/name" },
      { step: "address", url: "/onboarding/address" },
      { step: "review",  url: "/onboarding/review" },
    ],
  },
];

// 2. Initialize (in a layout or root component)
function OnboardingLayout({ children }) {
  useWaypointInitializer({ journeyId: "onboarding", tree: MY_TREE });
  return <>{children}</>;
}

// 3. Navigate from any step component
function NameStep() {
  useStepWaypoint("name");
  const { goNext, goBack } = useWaypoint();
  return (
    <>
      <button onClick={() => goBack()}>Back</button>
      <button onClick={() => goNext()}>Next</button>
    </>
  );
}
```
